# ⛪ فصل الشهيد العظيم مارجرجس الروماني | كنيسة السيدة العذراء مريم بالزيتون
> **لوحة المتابعة التفاعلية الشاملة وتطبيق الهاتف (St. George Sunday School Attendance & Visitation Dashboard)**

تطبيق أندرويد أصلي (Native Android APK) وتطبيق ويب تقدمي (PWA) متكامل صُمم خصيصاً لخدمة وتربية مخدومي فصل الشهيد العظيم مارجرجس بكنيسة السيدة العذراء مريم بالزيتون. يتيح متابعة الحضور الأسبوعي، الافتقاد، تسجيل الملاحظات، التحليلات الذكية المدعومة بالذكاء الاصطناعي Gemini، مع المزامنة التلقائية واللحظية المباشرة مع Google Sheets.

## ✨ المميزات الرئيسية

### 1. 🔄 المزامنة التلقائية الدورية ومؤشر التقدم (Auto-Sync)
- مزامنة خلفية تلقائية للبيانات مع Google Sheets كل **5 دقائق** طوال فترة فتح التطبيق.
- **مؤشر تقدم علوي أنيق**: شريط ضوئي تفاعلي متدرج أسفل الشريط العلوي (`Top Bar`) ينبض أثناء التحديث لتنبيه الخادم بالعملية الجارية دون حجب الشاشة أو تعطيل عمله.
- شارة حالة المزامنة توضح توقيت آخر تحديث ناجح، مع تأجيل المزامنة تلقائياً إذا كان الخادم يقوم بتعديل كارت نشط لحماية المدخلات.

### 2. 🤖 مساعد الذكاء الاصطناعي الرعوي (Gemini AI Assistant)
- مدعوم بـ **Firebase AI Logic** ونموذج `gemini-3.8-flash` المتقدم.
- يقدم تحليلات فورية لنسب الحضور والغياب، وتوليد رسائل افتقاد وتشجيع روحية موجهة باسم المخدوم، وتلخيص خطة المتابعة الأسبوعية للأشبين.

### 3. 🗂️ كروت المخدومين التفاعلية ثلاثية الأبعاد (3D Flip Cards)
- واجهة أمامية محمية للقراءة السريعة لمنع الخطأ في الإدخال، تعرض كود المخدوم، اسمه، الأشبين، العنوان، وحالة حضور الجمعة الحالية والمؤشر الشهري.
- إمكانية قلب الكارت ثلاثي الأبعاد بانسيابية لتعديل بيانات المخدوم، الأشبين، المنطقة، الهواتف، وملاحظات الافتقاد مع حفظ فوري على Google Sheets.

### 4. 🔤 الخط العربي الموحد (خط Almarai)
- اعتماد خط **المراعي (Almarai)** من Google Fonts في كامل واجهات التطبيق وأندرويد عبر ملفات موارد النظام `res/font/almarai.ttf` لضمان وضوح وقراءة مريحة ودعم العمل دون اتصال.

### 5. 📊 شريط التمرير الأفقي الذكي (Top Scroll Progress Bar)
- شريط أفقي ناعم مثبت بأعلى الشاشة يتمدد بنعومة بنسبة من `0%` إلى `100%` ليعكس بدقة موضع التمرير ونسبة تصفح قائمة الكروت.

### 6. 📱 القائمة الجانبية المحسنة (Drawer Menu)
- قائمة جانبية تنبثق بنعومة من اليمين (RTL) بأيقونة واحدة مخصصة لكل عنصر.
- تنقل فوري بين: الكروت، جدول الحضور، الإحصائيات، سجل الافتقاد، فلترة المناطق السكنية، ومساعد Gemini، مع إبقاء قسم «عن التطبيق» في نهاية القائمة.

### 7. 🛡️ أيقونة التطبيق وشاشة البداية الملكية (Splash Screen)
- الحفاظ على الأيقونة الأصلية للشهيد مارجرجس على الحصان بدقة كاملة في كافة أبعاد أيقونات الأندرويد والويب.
- شاشة بداية سينمائية متحركة ترسم وتبرز لوجو الشهيد مارجرجس مع تأثيرات الانبثاق والضوء.

### 8. 📈 إحصائيات متقدمة وتصدير شامل
- لوحة تحكم ذكية تعرض مؤشرات الأداء الرئيسية (KPIs)، متوسط الحضور، توزيع المخدومين على الخدام والمناطق.
- تصدير فوري لجداول البيانات إلى ملفات Excel (`.xlsx`)، تقارير PDF جاهزة للطباعة، ومشاركة التقارير بنقرة واحدة عبر WhatsApp.

## 🛠️ التقنيات المستخدمة

- **نظام التشغيل والتطبيق الأصلي**: Android (Kotlin, Jetpack Compose, Material 3, Android WebView Bridge).
- **الذكاء الاصطناعي والخدمات السحابية**: Firebase AI Logic (Gemini API `gemini-3.8-flash`), Google Cloud App Check.
- **تطبيق الويب PWA**: HTML5, CSS3 Custom Properties, JavaScript (ES6+), Bootstrap 5 RTL, FontAwesome 6.
- **الخطوط والطباعة**: Almarai Font Family (Google Fonts) مدمجة محلياً.
- **قواعد البيانات والمزامنة**: Google Sheets API, Google Apps Script Web App.
- **الرسوم البيانية والتصدير**: Chart.js 4, SheetJS (XLSX), html2pdf.js.

## 🚀 التشغيل والبناء محلياً

### بناء تطبيق أندرويد (Android Studio / Gradle):
```bash
# بناء نسخة الـ APK للتجربة
gradle assembleDebug

# ملف الـ APK الناتج:
# app/build/outputs/apk/debug/app-debug.apk
# ومتاح أيضاً في:
# app/St-Gorge-Dashboard.apk
```

